# Automação de Testes - Swag Labs

Projeto desenvolvido para a disciplina de Qualidade de Software.

## Ferramenta utilizada
- Playwright
- JavaScript

## Requisito automatizado
RF01 – Login

## Casos de teste automatizados
- CT01 – Login com credenciais válidas
- CT02 – Login com senha inválida
- CT03 – Login com usuário inválido
- CT04 – Login com campos vazios
- CT05 – Login com usuário bloqueado
